Research notes

Method and limitations.

The model is useful when its inputs, statistical protocol, and assumptions are understood.

01

Data and target

20,640 California census block groups from 1990. Predictions concern the area's median house value in historical US dollars, not an individual property's current market value.

02

Train and evaluation split

60% train, 20% validation and 20% held-out test, stratified by median-income category. The winning model is selected using validation RMSE, refit on development data and evaluated once on the test set.

03

Geographic feature comparison

Longitude, latitude and proximity to the ocean improved the random-split validation RMSE. This is an association; it is not a causal claim or a validation on entirely unseen geographies.

04

Spatial calculus

Tree predictions are discontinuous. GeoValue constructs a Gaussian-smoothed fixed-feature geographical scenario, evaluates numerical gradients in California Albers coordinates (EPSG:3310), and integrates supported grid cells.

05

Reproducibility

Training, numerical calculations and inference remain in tested Python modules. The web interface uses a trusted locally trained model and precomputed chart assets; it does not retrain on each request.

06

Known limitations

The historical target is upper-coded at $500,001. Grid resolution and smoothing affect derivative magnitudes. The supported grid region does not exactly match California's land boundaries.
