# Sample prediction inputs

`property-inputs.csv` illustrates the 19-field predictor contract used by the official residential-sale model. The rows are synthetic examples for software testing, not verified sales or property appraisals. Place names, ZIP values and structural attributes may not represent actual matching county records; categorical encoding tolerates unseen categories.

The authoritative field definitions and validation rules are in [`docs/official/SCHEMA.md`](../../../docs/official/SCHEMA.md).
